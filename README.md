# Emotion_Detection_AI

> **Fork.** This is a fork of [ibm-developer-skills-network/oaqjp-final-project-emb-ai](https://github.com/ibm-developer-skills-network/oaqjp-final-project-emb-ai), kept as coursework. It is not original work — the credit belongs to IBM SkillsBuild's AI Engineering capstone.

The project is the front end of an emotion-detection web app: a Flask page that takes a sentence and displays the emotion the backend classifies from it.

## What's in this fork

```
templates/index.html    the input page and result display
static/mywebscript.js   client script that posts the entered text and renders the response
LICENSE                 Apache 2.0, from the upstream project
```

The Python backend (the Flask app, `EmotionDetection` package and the Watson NLP call) lives in the upstream repository and is **not** included here, so this copy can't run on its own.

## Notes

Kept public as a record of the course. The upstream repository is the place to look for the working application.
